Storichat README- Link


Storichat is an AI-powered mental health chatbot designed to support users by responding to their questions with insights drawn from real, anonymized stories shared by others. While I leveraged AI tools throughout the development process, I also customized the code and made manual adjustments to the style. Additionally, I handled debugging with some assistance from AI, ensuring the final product was both functional and user-friendly.

 	Storichat allows users to ask questions about mental health challenges and receive responses generated from a growing collection of community-submitted stories and testimonies. Users can contribute their own experiences through a sidebar submission form, which updates the chatbot’s knowledge base in real-time. This dynamic memory feature sets Storichat apart from many other chatbots. Although it may not be as advanced as ChatGPT, Storichat uniquely adapts as new stories are added and supports usage by multiple users.

 Some risks with this app are that multiple users can use this app, so they can indirectly access information about stories people share.  The good news is the stories are anonymous, unless names and private identifying information are mentioned directly in the story, which is why it’s important to be careful not to put sensitive information when sharing stories. Another disclaimer is that this chat is not meant to be a diagnostic tool or a substitute for clinical therapy, so reaching out to a therapist should still be considered. But this is an excellent way for support groups to communicate with each of their members by sharing stories online. Therefore, this can be an excellent side tool. This was one of the reasons for building this app.

The AI models I used for assistance were Copilot, Claude, and Reply Agent. JSON is used to store some of the stories, and Python is used for the logic and programming needed for the site, and the Replit agent environment is used to display the site. This still took almost an hour to build, but it was a great example of prompt engineering.

​  	Hopefully, this app can be an excellent tool for social groups to use if it gets released.
